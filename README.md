# bca152-freertos-multisensor

Project initialized for BCA152.

## Project Overview
This project is a FreeRTOS-Based ESP32 Room Multisensor. The simulated device monitors room/environmental conditions and provides user interaction using components available in Wokwi.

## Hardware / Simulated Components
- ESP32 (Main microcontroller)
- DHT22 (Temperature and humidity)
- Photoresistor / LDR (Ambient light)
- PIR sensor (Motion detection)
- Rotary encoder (User input)
- SSD1306 OLED (Information display)
- Buzzer (Alarm output)
